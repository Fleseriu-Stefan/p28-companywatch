## A1 results

Eight synthetic trials were valid, with 25,001 target staging rows per trial
and 347,014 deletions across the recorded drains. The minimal Docker lifecycle
smoke test and all 46 offline tests passed. The eight projects and the smoke
project were fully removed. Runner and MySQL wait and inspect agreed on
exit codes 143 and 0 respectively. The protected-volume ownership labels
matched preflight. The two earlier invalid attempts remain separate from
this campaign.

All four paired purge comparisons remained **inconclusive**. The control
purge watermark advanced before the release checkpoint in every pair. The
held watermark advanced after release in every pair. The other two approved
criteria were not consistently met:

| Scenario | HLL before release, control / held | Held HLL before / final after release |
| --- | --- | --- |
| Retry | 24 / 79 | 79 / 80 |
| Successful finalization | 54 / 54 | 54 / 55 |
| Failure before copy | 54 / 54 | 54 / 55 |
| Failure after copy | 13 / 79 | 79 / 80 |

HLL is InnoDB history list length. All held snapshots passed the visibility
check. The 15-second window did not demonstrate a held HLL decline.
The pre-release checkpoints corresponded to the same workload phase.
Post-release endpoints were uneven because the controls stopped sampling once
they met their baseline. The batch and terminal timings are descriptive.
SQL rows examined and handler counters leave physical traversal unmeasured.
The retry terminal probe remains outside the treatment comparison.
